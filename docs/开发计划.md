# 开发状态与后续计划

2026-10-27 对照当前 Python 与同级 Java 仓库源码更新。以下“已实现”指代码存在，测试数据库、服务器及真实网页的运行结果需另行验收。

## 已实现

- FastAPI 任务 API、Worker 注册、内存任务状态、执行并发上限与超时。
- Mock、Meta Ads Library 和 Google Ads Transparency 公开网页抓取；两个真实 Worker 已不是占位实现。
- Python SQLite 任务审计和按 `media + externalAdID` 更新的最新素材。
- Java `CreativeWorkerCallbackController` / `CreativeWorkerCallbackService` 回调、运行记录持久化及素材 upsert。
- Java `CreativeLibraryService` 通过现有 Quartz 触发入口派发任务；`CreativeLibrarySyncJob` / `CreativeWorkerScheduleService` 扫描启用配置、创建运行并提交 Python。
- 素材表、CMS 菜单和 Quartz 作业注册 SQL 已在 Java 仓库提供；存在脚本不代表已在某个库执行。
- 本地验收统一复用 Java 现有测试环境；线上以宝塔 Python 项目面板管理，详见对应操作文档。

## 历史网页烟测记录（2026-10-26）

以下保留原文档的历史测试记录，本次文档核对没有重新执行真实网页抓取；不能视为当前服务器、网络和页面仍然通过的证明。

- Meta：`keyword=game`、`country=HK`，Playwright 加载到广告结果，单次提取 3 条素材；页面 HTTP 状态为 403，但页面仍渲染了结果卡片，因此实现按“是否有结果卡片”判断成功，不能只按 HTTP 状态判断。
- Google：`advertiserName=supercell`、`region=HK`，搜索到 `Supercell Oy`，进入广告主详情页后提取到 3 条素材，包含 `advertiserID`、`creativeId`、`versionId` 和详情 URL。
- 指定样例：Facebook `螺丝` + `country=ALL` 页面显示约 260 条结果，本次提取前 5 条；Google `SOFISH TECHNOLOGY PTE. LTD.` + `region=SG` 页面显示约 412 条广告，本次提取前 5 条。
- 替代查询：Meta `手机壳` 抓取 2 条、Google `Supercell Oy` + `region=HK` 抓取 2 条；Meta `游戏` 抓取 1 条、Google `Playrix` + `region=HK` 抓取 1 条，均未登录且返回 `SUCCESS`。
- 替代查询统一使用 `python scripts/live_smoke_test.py --meta-keyword "手机壳" --google-advertiser "Supercell Oy" --google-region HK`，便于小规模复验其他关键词和竞品公司。
- 两个平台都没有调用 Graph API、Google Ads API 或附件中的 access token。
- 测试截图保存在本地 `evidence/`，该目录已加入 `.gitignore`，不会提交浏览器页面内容。

## 已知限制与后续开发

| 事项 | 当前情况 / 后续工作 |
| --- | --- |
| 回调可靠性 | 目前只发一次；补充持久化重试、失败可观测性及恢复流程。回调错误暂未再次写入 SQLite |
| 重启与卡住的运行 | 实时任务只在内存；Java 会跳过 DISPATCHED / RUNNING 配置，需要设计超时回收、对账和安全重试 |
| 新增 / 更新计数 | 当前网页结果数直接作为 newCount，未与历史数据比较；需实现真实增量计数 |
| 回调幂等 | Java 当前使用内存指纹，非持久化全量 payload 去重；需明确重复、变更和乱序回调处理策略 |
| Java 代理配置贯通 | Python API 有代理字段，但现有 Quartz 派发未传；只填默认代理环境变量不会自动生效 |
| 认证代理与错误脱敏 | 现有 Worker 未调用代理认证字段拆分方法，需要验证带认证代理并完善异常脱敏与分类 |
| 浏览器登录与人工处理 | 当前为无登录的 headless 会话；持久化 Profile、人工接管及截图证据尚未实现 |
| 抓取范围 | 多地区逐一合并、按 window 时间过滤、按 advertiserID 精准定位尚未实现；滚动存在上限，不能承诺全量 |
| 平台结果稳定性 | Google 首个联想结果及位置派生 ID 需要加强匹配与稳定身份验证；页面改版需持续维护 |
| 媒体资产 | Python 当前保存 URL / 元数据；对象存储下载、保留周期及重试需单独设计 |
| 可选官方 API | Meta Graph API 等属于按权限和需求评估的后续方案，不是当前运行依赖 |

详见[架构设计](架构设计.md)和[接口契约](接口契约.md)。本次仅修正文档，没有实现上表中的功能。

## 当前验收顺序

1. 复用 Java 测试配置，核对现有素材表、菜单和 Quartz 注册任务，不另建数据库。
2. 启动 Worker，完成健康检查及不回调 Java 的 Mock。
3. 需要完整业务链路时启动 Manager、Quartz 和 CMS；直接网页烟测不需要这些服务。
4. 小规模验证全部启用配置扫描的实际范围，再从 CMS 触发并确认 Java 回调入库。
5. 用相同素材验证唯一键去重；检查最终数据，不把 newCount 当作真实数据库新增数。
6. 完成验证码、回调失败、重启恢复等边界检查后，再按测试 / 生产环境约定开启周期调度。

具体操作见[本地验收](本地验收.md)与[部署上线](部署上线.md)。
