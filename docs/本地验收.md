# 本地双项目验收

## 1. 启动测试数据库

在 Python Worker 仓库执行：

```powershell
docker compose -f docker-compose.local.yml up -d
docker compose -f docker-compose.local.yml ps
```

MySQL 映射到 `127.0.0.1:53307`，数据库为 `sdkgamedb0`，账号 `gamedis/gamedis_local`。Redis 映射到 `127.0.0.1:63790`，密码为 `redis_local`。这些只用于本地测试，不要用于生产。

## 2. 建表

```powershell
Get-Content ..\id-game-distribution-servers\docs\statistics\素材库\creative-schema.sql | docker exec -i creative-worker-mysql mysql -ugamedis -pgamedis_local sdkgamedb0
```

## 3. 启动 Java Manager

先在 Java 仓库打包，再直接运行可执行 JAR。这样可以避免 Maven 聚合项目选择主类失败，也避免 Windows 命令行过长：

```powershell
mvn -pl sf-manager-xstarter -am -DskipTests package
java -jar sf-manager-xstarter/target/sf-manager-xstarter-1.0.0.jar `
  --server.port=13367 `
  --spring.shardingsphere.datasource.sdkgamedb0.url="jdbc:mysql://127.0.0.1:53307/sdkgamedb0?allowPublicKeyRetrieval=true&useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai" `
  --spring.shardingsphere.datasource.sdkgamedb0.username=gamedis `
  --spring.shardingsphere.datasource.sdkgamedb0.password=gamedis_local `
  --spring.redis.host=127.0.0.1 --spring.redis.port=63790 --spring.redis.password=redis_local `
  --spring.session.store-type=none --eureka.client.enabled=false `
  --eureka.client.register-with-eureka=false --eureka.client.fetch-registry=false
```

如果只需要编译检查而不启动完整 Manager，可执行：

```powershell
mvn -pl sf-manager-web -am -DskipTests compile
```

## 4. 启动 Python Worker

在 Python 仓库执行：

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8091
```

## 5. 通过两个 Worker 抓取并回调入库

Meta：

```powershell
$body = @{ worker = "meta_library"; runId = 2026102601; payload = @{ keyword = "螺丝"; countryCodes = @("ALL"); activeStatus = "active"; adType = "all"; mediaType = "all"; maxResults = 5 } } | ConvertTo-Json -Depth 8
Invoke-RestMethod http://127.0.0.1:8091/jobs -Method Post -ContentType "application/json" -Body $body
```

Google：

```powershell
$body = @{ worker = "google_transparency"; runId = 2026102602; payload = @{ advertiserName = "SOFISH TECHNOLOGY PTE. LTD."; region = "SG"; maxResults = 5 } } | ConvertTo-Json -Depth 8
Invoke-RestMethod http://127.0.0.1:8091/jobs -Method Post -ContentType "application/json" -Body $body
```

返回 `202` 后等待任务完成，再查询 Python 状态：

```powershell
Invoke-RestMethod http://127.0.0.1:8091/jobs/<jobId>
```

## 6. 验证两个数据库

Python 本地 SQLite：

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/worker.db'); print(c.execute('select job_id,run_id,worker,status,fetched_count from worker_job').fetchall()); print(c.execute('select source,external_ad_id from worker_item').fetchall())"
```

Java MySQL：

```powershell
docker exec creative-worker-mysql mysql -ugamedis -pgamedis_local sdkgamedb0 -e "select run_id,worker,status,fetched_count,new_count from creative_run; select source,external_ad_id,advertiser_name from creative_item order by id desc limit 20;"
```

如果 Java 尚未启动，Python 的 SQLite 记录仍会保留；Java 启动后重新提交任务即可验证 Manager 回调和 MySQL 入库。重复提交同一个素材时，`creative_item` 的 `(source, external_ad_id)` 唯一键会执行更新，不会重复插入。
