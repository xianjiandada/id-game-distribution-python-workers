# Python Worker 接口契约

服务默认监听 `127.0.0.1:13371`。当前业务链路由 Java Quartz 提交任务，Python 完成后回调 Java Manager。本文于 2026-10-27 对照当前源码更新；本地联调复用 Java 已有测试数据库。

## `GET/POST /health`

响应：

```json
{"status":"UP","service":"id-game-distribution-python-workers","environment":"local"}
```

## `GET /workers`

响应：

```json
{"workers":["google_transparency","meta_library","mock"]}
```

## `POST /jobs`

以下为字段示意，runID / queryID / appID 不是可直接用于共享测试库的固定值。仅验证 Python 时去掉 `runID` 和 `callbackUrl`，不需要配置代理：

```json
{
  "worker": "mock",
  "runID": 10001,
  "proxyRequired": false,
  "payload": {"items": [{"externalAdID": "demo-1", "mediaType": "VIDEO"}]},
  "callbackUrl": "http://127.0.0.1:13367/internal/creative/runs/10001/callback"
}
```

回调地址优先级：任务 `callbackUrl` > `JAVA_CALLBACK_BASE_URL` + `/{runID}/callback`。没有显式 URL，且缺少基础地址或 runID 时跳过回调。当前 Quartz 会主动传 `callbackUrl`，开发回调本机 `13367`、生产回调 `https://api-manager.mar2game.com/internal/creative/runs/{runID}/callback`；只改 Python 默认地址不会覆盖它。

代理为可选字段，可在请求顶层增加 `"proxyProfile":"google_hk","proxyRequired":true`。解析顺序为 Profile 对应环境变量、`PROXY_DEFAULT_URL`；要求代理但都未配置时返回 `503`。未传 Profile 且 `proxyRequired=false` 时直接不用代理，即使设置了默认 URL。指定可选 Profile 但无配置时可直连，非法代理配置也会返回 `503`。当前 Java Quartz 尚未下发这两个字段，Python API 支持不代表完整业务链路已启用代理。

接口返回 HTTP `202`，仅表示已接受任务：

```json
{
  "jobID":"7e...",
  "runID":10001,
  "worker":"mock",
  "status":"DISPATCHED",
  "acceptedAt":"2026-10-26T10:00:00Z"
}
```

## `GET /jobs/{jobID}`

查询进程内存中的任务。状态包括 `DISPATCHED`、`RUNNING`、`SUCCESS`、`PARTIAL_SUCCESS`、`FAILED`、`WAITING_MANUAL`、`TIMEOUT`。不存在或进程重启后的旧 jobID 返回 `404`，不会自动读取 SQLite 恢复。

提交未知 Worker 返回 `400`；请求结构校验失败通常返回 `422`。HTTP `202` 与任务最终成功是两回事，抓取 `SUCCESS` 与 Java 回调成功也不同。回调失败会保留抓取状态并在没有原错误时标记 `CALLBACK_FAILED`；当前无自动补发，且回调错误不会再次写回 SQLite。

## 网页 Worker 参数示例

### 产品和查询上下文

Java Quartz 调用 Python 时，将下面的上下文放进 `payload`。`queryID`、`appID`、`productName` 用于审计和业务归属；`keyword` 同时会影响网页搜索。`windowStart` / `windowEnd` 随运行与回调保留，但当前不用于过滤网页结果：

```json
{
  "queryID": 20001,
  "appID": 1001,
  "productName": "示例产品",
  "keyword": "竞品名称",
  "windowStart": "2026-10-25T00:00:00Z",
  "windowEnd": "2026-10-26T00:00:00Z"
}
```

`appID` 是产品主维度；同一个产品可以配置多个 `queryID`。宿主给每条 item 补充缺失的 `queryID`、`appID`、`productName`、`keyword`、`media` 和 `contentHash`；时间窗口保留在任务 / 顶层回调，不自动复制到每条 item。回调中的 `collectionDate`、`collectedAt` 由宿主按 UTC 完成时间生成。最新素材按 `media + externalAdID` 唯一，跨查询重复素材会更新归属上下文，不为每个 queryID 另存快照。

Meta 公开网页：

```json
{
  "worker": "meta_library",
  "runID": 10002,
  "proxyProfile": "meta_hk",
  "proxyRequired": false,
  "payload": {
    "queryID": 20001,
    "appID": 1001,
    "productName": "示例产品",
    "keyword": "game",
    "countryCodes": ["HK"],
    "activeStatus": "active",
    "mediaType": "all",
    "maxResults": 20
  }
}
```

Google Ads Transparency：

```json
{
  "worker": "google_transparency",
  "runID": 10003,
  "proxyProfile": "google_hk",
  "proxyRequired": false,
  "payload": {
    "queryID": 20002,
    "appID": 1001,
    "productName": "示例产品",
    "advertiserName": "supercell",
    "region": "HK",
    "maxResults": 20
  }
}
```

网页抓取结果的 `items` 包含平台来源、外部素材 ID、广告主、详情 URL 和可用的预览/媒体地址。真实网页遇到验证码或没有结果卡片时，Worker 返回 `WAITING_MANUAL` 或明确失败码。

### 当前参数行为与结果限制

| 参数 / 字段 | 当前行为 |
| --- | --- |
| Meta `keyword` / `q` | 优先用 `keyword`，否则用 `q` 搜索 |
| Meta `countryCodes` / `country` | 只使用数组第一项；未提供时使用 `country`，最终缺省为 `ALL` |
| Google `advertiserName` / `keyword` | 优先用广告主名称，否则关键词；点击首个联想结果，尚未用 `advertiserID` 精准定位 |
| Google `region` / `countryCodes` | 显式 region 优先，其次数组第一项，缺省或 ALL 为 `ANYWHERE`；烟测脚本单独默认 SG |
| `maxResults` | 正整数是结果条数上限；0 / null / 缺省不设条数上限，仍受滚动最多 100 轮、连续 3 轮无增长及宿主执行超时约束 |
| `newCount` / `updatedCount` | 网页 Worker 暂将返回条数作为 newCount，updatedCount 默认 0；不是数据库去重后的真实增量 |
| `identityConfidence` | Google 无稳定 creativeId 时会产生 `position-*` 派生 ID，标记 DERIVED；不能视为跨查询稳定身份 |

API 当前对负数 / 无法解析的 `maxResults` 也按无限条数处理；请只使用非负整数或 null。烟测命令行有独立校验，只接受 0–1000。

## Java 回调

Python 完成后向：

```text
POST /internal/creative/runs/{runID}/callback
Content-Type: application/json
```

请求体：

```json
{
  "runID": 10001,
  "jobID": "7e...",
  "worker": "mock",
  "status": "SUCCESS",
  "queryID": 20001,
  "appID": 1001,
  "productName": "示例产品",
  "keyword": "竞品A",
  "media": "META_LIBRARY_WEB",
  "collectionDate": "2026-10-26",
  "collectedAt": "2026-10-26T10:00:00Z",
  "windowStart": "2026-10-25T00:00:00Z",
  "windowEnd": "2026-10-26T00:00:00Z",
  "fetchedCount": 1,
  "newCount": 1,
  "updatedCount": 0,
  "items": [{
    "externalAdID":"demo-1",
    "identityConfidence":"STABLE",
    "contentHash":"sha256...",
    "platformData": {"format":"VIDEO"}
  }],
  "errorCode": null,
  "errorMessage": null
}
```

Java Manager 当前校验路径与请求体 runID 一致、状态合法；运行记录不存在时会创建记录，并非严格拒绝未知 runID。正常业务 runID 由 Quartz 生成；传入的 queryID 需要满足业务库外键约束。素材按 `media + externalAdID` upsert。

重复回调通过进程内的 `runID → jobID|status|fetchedCount|newCount|updatedCount` 指纹识别，命中返回 HTTP 200；指纹不覆盖全部 items 内容且重启不保留，不能作为持久化精确去重保证。素材唯一键仍约束重复插入。

回调方法使用 `@NoNeedLogin` 和 `@NoNeedCheckHeader` 放行，Python `/jobs` 也没有独立鉴权。当前 Java 生产回调使用 HTTPS 域名，部署需限制来源和内部接口访问，不能把代码中的域名等同于已实施内网隔离。详细限制见[架构设计](架构设计.md)。
