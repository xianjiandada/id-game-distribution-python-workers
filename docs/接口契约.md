# Python Worker 接口契约

服务默认监听 `127.0.0.1:13371`。当前业务链路由 Java Quartz 提交任务，Python 完成后回调 Java Manager。本文于 2026-10-27 对照当前源码更新；本地联调复用 Java 已有测试数据库。

## `GET/POST /health`

响应：

```json
{"status":"UP","service":"id-game-distribution-python-workers","environment":"local"}
```

## `GET /workers`

响应：

```json
{"workers":["google_transparency","meta_library"]}
```

## `POST /jobs`

以下为字段示意，runID / queryID 不是可直接用于共享测试库的固定值。仅验证 Python 时去掉 `runID` 和 `callbackUrl`：

```json
{
  "worker": "meta_library",
  "runID": 10001,
  "payload": {"keyword": "File Recovery", "maxResults": 1},
  "callbackUrl": "http://127.0.0.1:13367/admin/creative/runs/10001/callback"
}
```

回调地址优先级：任务 `callbackUrl` > `JAVA_CALLBACK_BASE_URL` + `/{runID}/callback`。没有显式 URL，且缺少基础地址或 runID 时跳过回调。当前 Quartz 会主动传 `callbackUrl`，开发回调本机 `13367`、生产回调 `https://api-manager.mar2game.com/admin/creative/runs/{runID}/callback`；只改 Python 默认地址不会覆盖它。

Worker 回调会额外返回 `restrictionType` 和 `restrictionEvidence`。平台验证码或人工验证归类为 `CAPTCHA_REQUIRED`，限流归类为 `RATE_LIMITED`，访问拒绝或页面挑战归类为 `IP_RESTRICTED`。

接口返回 HTTP `202`，仅表示已接受任务：

```json
{
  "jobID":"7e...",
  "runID":10001,
  "worker":"meta_library",
  "status":"DISPATCHED",
  "acceptedAt":"2026-10-26T10:00:00Z"
}
```

## `GET /jobs/{jobID}`

查询进程内存中的任务。状态包括 `DISPATCHED`、`RUNNING`、`SUCCESS`、`PARTIAL_SUCCESS`、`FAILED`、`WAITING_MANUAL`、`TIMEOUT`。不存在或进程重启后的旧 jobID 返回 `404`，不会自动读取 SQLite 恢复。

提交未知 Worker 返回 `400`；请求结构校验失败通常返回 `422`。HTTP `202` 与任务最终成功是两回事，抓取 `SUCCESS` 与 Java 回调成功也不同。回调失败会保留抓取状态并在没有原错误时标记 `CALLBACK_FAILED`；当前无自动补发，回调错误会保存到 SQLite。

## 网页 Worker 参数示例

### 查询上下文

 Java Quartz 调用 Python 时，将下面的上下文放进 `payload`。`queryID` 用于关联查询配置，`keyword` 或 `advertiserName` 同时会影响网页搜索。`windowStart` / `windowEnd` 随运行与回调保留，但当前不用于过滤网页结果：

```json
{
  "queryID": 20001,
  "keyword": "竞品名称",
  "windowStart": "2026-10-25T00:00:00Z",
  "windowEnd": "2026-10-26T00:00:00Z"
}
```

 同一平台可以配置多个 `queryID`。宿主给每条 item 补充缺失的 `queryID`、`keyword`、`media` 和 `contentHash`。时间窗口保留在任务和顶层回调，不自动复制到每条 item。回调中的 `collectionDate`、`collectedAt` 由宿主按 UTC 完成时间生成。最新素材按 `media + externalAdID` 唯一，跨查询重复素材会更新查询上下文，不为每个 queryID 另存快照。

Meta 公开网页：

```json
{
  "worker": "meta_library",
  "runID": 10002,
  "payload": {
    "queryID": 20001,
    "keyword": "game",
    "countryCodes": ["HK"],
    "activeStatus": "active",
    "mediaType": "all",
    "maxResults": 20
  }
}
```

Google Ads Transparency：

```json
{
  "worker": "google_transparency",
  "runID": 10003,
  "payload": {
    "queryID": 20002,
    "advertiserName": "supercell",
    "region": "HK",
    "maxResults": 20
  }
}
```

网页抓取结果的 `items` 使用同一套素材主字段，平台无法可靠提供的字段保持为空，不用占位值填充。Google 和 Meta 当前共用这些字段：

| 主字段 | Google Ads Transparency | Meta Ads Library |
| --- | --- | --- |
| `media`、`externalAdID`、`identityConfidence` | creative ID、稳定 | Library ID、稳定 |
| `advertiserID`、`advertiserName` | 广告主 URL 中的 AR ID、名称 | 名称，页面没有稳定 ID 时留空 |
| `title`、`description`、`copyText` | 预览脚本/iframe 文案 | 卡片广告文案写入 `copyText` |
| `function`、`language` | 从标题和文案推断 | 从卡片文案推断 |
| `mediaType`、`mediaUrl` | 预览视频或图片 | 卡片视频或图片 |
| `landingUrl`、`snapshotUrl`、`sourceUrl` | 素材详情/页面地址 | 广告落地页、Library 详情地址、查询页面地址 |
| `deliveryStartTime` | 页面没有稳定值时留空 | 从 `Started running on ...` 转为日期 |
| `youtubeVideoId`、`youtubeVideoUrl`、`youtubeTitle`、`youtubeDurationSeconds`、`youtubeViewCount` | 能关联 YouTube 时填写 | 当前公开卡片没有可靠来源时留空 |

渠道独有字段统一放在 `platformData`，Java 入库后保存到 `advert_creative_item.platformDataJson`。例如 Meta 的 `libraryId`、`startedText`、查询筛选参数和原始媒体地址，以及 Google 的 `versionId`、`cardLabel`、预览脚本地址和解析出的产品/包名。后续增加渠道时先复用主字段，只有确实无法统一的字段才进入这个 JSON 扩展字段。

真实网页遇到验证码或没有结果卡片时，Worker 返回 `WAITING_MANUAL` 或明确失败码。

### 当前参数行为与结果限制

| 参数 / 字段 | 当前行为 |
| --- | --- |
| Meta `keyword` / `q` | 优先用 `keyword`，否则用 `q` 搜索 |
| Meta `countryCodes` / `country` | 只使用数组第一项；未提供时使用 `country`，最终缺省为 `ALL` |
| Google `advertiserName` / `keyword` | 优先用广告主名称，否则关键词；点击首个联想结果，尚未用 `advertiserID` 精准定位 |
| Google `region` / `countryCodes` | 显式 region 优先，其次数组第一项，缺省或 ALL 为 `ANYWHERE`；烟测脚本单独默认 SG |
| `maxResults` | 正整数是结果条数上限；0 / null / 缺省不设条数上限，仍受滚动最多 100 轮、连续 3 轮无增长及宿主执行超时约束 |
| `newCount` / `updatedCount` | 网页 Worker 暂将返回条数作为 newCount，updatedCount 默认 0；不是数据库去重后的真实增量 |
| `identityConfidence` | Google 无稳定 creativeId 时会产生 `position-*` 派生 ID，标记 DERIVED；不能视为跨查询稳定身份 |

API 当前对负数 / 无法解析的 `maxResults` 也按无限条数处理；请只使用非负整数或 null。烟测命令行有独立校验，只接受 0–1000。

## Java 回调

Python 完成后向：

```text
POST /admin/creative/runs/{runID}/callback
Content-Type: application/json
```

请求体：

```json
{
  "runID": 10001,
  "jobID": "7e...",
  "worker": "meta_library",
  "status": "SUCCESS",
  "queryID": 20001,
  "keyword": "竞品A",
  "media": "META_LIBRARY_WEB",
  "collectionDate": "2026-10-26",
  "collectedAt": "2026-10-26T10:00:00Z",
  "windowStart": "2026-10-25T00:00:00Z",
  "windowEnd": "2026-10-26T00:00:00Z",
  "fetchedCount": 1,
  "newCount": 1,
  "updatedCount": 0,
  "items": [{
    "externalAdID":"demo-1",
    "identityConfidence":"STABLE",
    "contentHash":"sha256...",
    "platformData": {"format":"VIDEO"}
  }],
  "errorCode": null,
  "errorMessage": null
}
```

Manager 只接受已有运行 ID 的回调。素材按平台和广告 ID 更新；运行表根据实际入库结果记录新增和内容变更数量。

相同运行、任务和终态的回调由数据库去重。Manager 在媒体归档和数据库事务完成后返回，批量任务通过现有 CALLBACK_TIMEOUT_SECONDS 设置等待时间，默认 1800 秒。

回调方法使用 `@NoNeedLogin` 和 `@NoNeedCheckHeader` 放行，Python `/jobs` 也没有独立鉴权。当前 Java 生产回调使用 HTTPS 域名，部署需限制来源和内部接口访问，不能把代码中的域名等同于已实施内网隔离。详细限制见[架构设计](架构设计.md)。
