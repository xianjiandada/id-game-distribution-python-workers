# Python Worker 接口契约

服务默认监听 `127.0.0.1:8091`。生产中由 Java Manager 通过本机或内网调用。

## `GET/POST /health`

响应：

```json
{"status":"UP","service":"id-game-distribution-python-workers","environment":"local"}
```

## `GET /workers`

响应：

```json
{"workers":["google_transparency","meta_library","mock"]}
```

## `POST /jobs`

请求：

```json
{
  "worker": "mock",
  "runId": 10001,
  "proxyProfile": "google_hk",
  "proxyRequired": true,
  "payload": {"items": [{"externalAdId": "demo-1", "mediaType": "VIDEO"}]},
  "callbackUrl": "http://127.0.0.1:8080/internal/creative/runs/10001/callback"
}
```

`callbackUrl` 本地测试可传；生产建议不由外部调用方任意指定，使用 `JAVA_CALLBACK_BASE_URL` 根据 `runId` 拼接 Manager 地址。接口返回 HTTP `202`：

`proxyProfile` 是服务端配置的逻辑名称，不是代理 URL。`proxyRequired=true` 且服务器没有对应代理时，接口返回 `503`，不会创建一个假任务。代理地址只在 Worker 进程内存中使用。

```json
{
  "jobId":"7e...",
  "runId":10001,
  "worker":"mock",
  "status":"DISPATCHED",
  "acceptedAt":"2026-10-26T10:00:00Z"
}
```

## `GET /jobs/{jobId}`

查询任务状态。状态包括 `DISPATCHED`、`RUNNING`、`SUCCESS`、`PARTIAL_SUCCESS`、`FAILED`、`WAITING_MANUAL`、`TIMEOUT`。

## 网页 Worker 参数示例

### 产品和查询上下文

Java Manager 调用 Python 时，应把下面的上下文放进 `payload`。这些字段不会改变 Meta/Google 的网页查询参数，但会随回调写入 Java 素材库，支持按产品、搜索词和日期区分数据：

```json
{
  "queryId": 20001,
  "appId": 1001,
  "productName": "示例产品",
  "keyword": "竞品名称",
  "windowStart": "2026-10-25T00:00:00Z",
  "windowEnd": "2026-10-26T00:00:00Z"
}
```

`appId` 是产品主维度；同一个产品可以配置多个 `queryId`，分别保存不同平台、关键词、广告主和地区。Python 会把这些字段补到每条 `items`，回调中的 `collectionDate`、`collectedAt` 由 Worker 自动生成。

Meta 公开网页：

```json
{
  "worker": "meta_library",
  "runId": 10002,
  "proxyProfile": "meta_hk",
  "proxyRequired": false,
  "payload": {
    "queryId": 20001,
    "appId": 1001,
    "productName": "示例产品",
    "keyword": "game",
    "countryCodes": ["HK"],
    "activeStatus": "active",
    "mediaType": "all",
    "maxResults": 20
  }
}
```

Google Ads Transparency：

```json
{
  "worker": "google_transparency",
  "runId": 10003,
  "proxyProfile": "google_hk",
  "proxyRequired": false,
  "payload": {
    "queryId": 20002,
    "appId": 1001,
    "productName": "示例产品",
    "advertiserName": "supercell",
    "region": "HK",
    "maxResults": 20
  }
}
```

网页抓取结果的 `items` 包含平台来源、外部素材 ID、广告主、详情 URL 和可用的预览/媒体地址。真实网页遇到验证码或没有结果卡片时，Worker 返回 `WAITING_MANUAL` 或明确失败码。

## Java 回调

Python 完成后向：

```text
POST /internal/creative/runs/{runId}/callback
Content-Type: application/json
```

请求体：

```json
{
  "runId": 10001,
  "jobId": "7e...",
  "worker": "mock",
  "status": "SUCCESS",
  "queryId": 20001,
  "appId": 1001,
  "productName": "示例产品",
  "keyword": "竞品A",
  "source": "META_LIBRARY_WEB",
  "collectionDate": "2026-10-26",
  "collectedAt": "2026-10-26T10:00:00Z",
  "windowStart": "2026-10-25T00:00:00Z",
  "windowEnd": "2026-10-26T00:00:00Z",
  "fetchedCount": 1,
  "newCount": 1,
  "updatedCount": 0,
  "items": [{
    "externalAdId":"demo-1",
    "identityConfidence":"STABLE",
    "contentHash":"sha256...",
    "platformData": {"format":"VIDEO"}
  }],
  "errorCode": null,
  "errorMessage": null
}
```

Java Manager 回调方法使用 `@NoNeedLogin` 和 `@NoNeedCheckHeader` 放行；仍必须检查 `runId` 是否存在，按 `runId` 幂等更新运行记录，并对 `source + externalAdId` 做素材 upsert。重复回调返回 200，不得重复插入。接口只允许 Python 与 Java 的本机/内网访问，不开放公网。
